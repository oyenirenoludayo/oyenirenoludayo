case_03 // pxe_imaging_standardization

PXE Automated Imaging & Data Migration Standardization

RoleDesktop Support Technician
ContextRaritan Pharmaceutical Company
DisciplineImaging · Automation · Data Migration

Overview

Streamlined device provisioning across lab workstations to reduce deployment times and eliminate data loss during hardware refreshes.

Approach

  1. Image architecture — built a standardized, generalized Windows image containing core pharmaceutical utility software, security agents and network configurations using SCCM / Microsoft Endpoint Configuration Manager (MECM).
  2. PXE network setup — configured DHCP option tags (66/67) and IP helpers across network switches to route lab subnets to the PXE boot server securely.
  3. Data migration pipeline — developed automated USMT (User State Migration Tool) XML scripts to capture user profiles, application settings and local lab configuration files to an encrypted network share prior to re-imaging.
  4. Validation & deployment — performed PXE boot deployments on target hardware, executed state restoration, verified application checksums and validated user permissions.
  5. Documentation & artifacts — produced a Standard Operating Procedure for PXE boot troubleshooting, USMT XML migration templates, and a pre-deployment hardware verification checklist.
Fig. 1 — Imaging & Migration Pipeline (original diagram)
Image Architecture→ PXE Network Setup→ Data Migration→ Validation & Deployment→ Documentation
Original illustration — PXE boot & image deployment. Not an actual SCCM console screenshot.

Focus Areas

SCCM/MECM image management, PXE and DHCP network configuration, USMT-based data migration, deployment validation, and SOP documentation for repeatable rollout.

case_04 // lab_cabling_hardening

Pharmaceutical Lab Cabling Infrastructure & Hardware Hardening

RoleDesktop Support Technician
ContextRaritan Pharmaceutical Company
DisciplineStructured Cabling · Hardware Deployment · Compliance

Overview

Redesigned physical cabling and deployed lab-grade printing and labeling hardware within compliance-critical zones to ensure operational cleanliness and audit readiness.

Approach

  1. Site assessment & mapping — conducted a physical audit of lab workstations, cleanrooms and testing bays to map structured cabling paths, network drop capacity and power infrastructure.
  2. Structured cabling deployment — installed Cat6a cabling terminating in patch panels, using color-coded patch cords to separate lab-critical from standard administrative networks; secured runs with drop-ceiling trays and high-density, wipeable cable management raceways.
  3. Lab hardware integration — positioned, assembled and configured industrial thermal label printers (Zebra) and specialized analytical instrument controllers; applied static IP configurations and established print server queues with restricted access controls.
  4. Environmental hardening — installed protective enclosures and cable seals around connections to meet lab sanitization protocols.
  5. Documentation & artifacts — produced a physical network topology map, a cable labeling scheme register, and a Hardware Installation Compliance Protocol document for cleanroom environments.
Fig. 1 — Deployment Sequence (original diagram)
Site Assessment→ Structured Cabling→ Hardware Integration→ Environmental Hardening→ Documentation
Original illustration — structured cabling & patch panel layout. Not an actual site photo.

Focus Areas

Cat6a structured cabling, cleanroom-compliant hardware deployment, Zebra thermal printer and instrument controller integration, static IP/print server configuration, and compliance documentation.

case_05 // itam_preventive_maintenance

IT Asset Management & Preventive Maintenance Framework

RoleDesktop Support Technician
ContextRaritan Pharmaceutical Company
DisciplineAsset Management · Preventive Maintenance · Lifecycle Tracking

Overview

Established a centralized hardware inventory system paired with a proactive maintenance schedule for critical pharmaceutical IT hardware to prevent unscheduled downtime.

Approach

  1. Inventory baseline & tagging — performed a full sweep of desktop computers, monitors, specialized lab interfaces and printers; affixed barcode/asset tags and logged serial numbers, MAC addresses, warranty status and lab zone assignments into an ITSM platform (e.g., ServiceNow).
  2. Maintenance protocol design — created a recurring preventive maintenance schedule (quarterly/semi-annually) prioritizing high-utilization lab computers and thermal printers.
  3. Component replacement execution — cleaned dust filters, inspected thermal compounds, replaced degrading hardware components (RAM, storage drives, power supplies), and calibrated label printer sensors.
  4. Lifecycle tracking — logged all maintenance events, component upgrades and retirements within the ITSM database to track asset health trends and plan hardware refresh cycles.
  5. Documentation & artifacts — produced an IT Asset Lifecycle SOP, a Preventive Maintenance Checklist for lab workstations, and a Monthly Asset Health & Component Replacement Log template.
Fig. 1 — Maintenance Cycle (original diagram · recurring quarterly/semi-annually)
Inventory & Tagging→ Maintenance Protocol→ Component Replacement→ Lifecycle Tracking↻
Original illustration — asset lifecycle & preventive maintenance. Not an actual ServiceNow screenshot.

Focus Areas

ITSM/ServiceNow-based asset tracking, preventive maintenance scheduling, component-level hardware repair, and lifecycle documentation.
